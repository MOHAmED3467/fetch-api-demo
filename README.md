# 🛍️ Fetch API Demo

This project demonstrates how to use the **Fetch API** in JavaScript with both:
- **.then() Promises**
- **async/await**

It fetches random products from the [DummyJSON API](https://dummyjson.com/products) and displays:
- 📝 Product Name  
- 💰 Price  
- 🖼️ Thumbnail Image  

---

## 🚀 Features
- Fetch product data dynamically using Fetch API.
- Compare two approaches:
  - Using `.then()`
  - Using `async/await`
- Random product on every refresh.
- Modern card-based UI with hover effects.
- Responsive design.
